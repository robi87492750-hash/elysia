# Third-party and character asset notices

## Current Elysia character package

`characters/elysia/` contains the maid Elysia source images, generated still image, icon and WebM animations. The project owner states that the source illustrations were generated with GPT; the still image, icon and clips were produced from them by this project's asset script. The design references Elysia from *Honkai Impact 3rd* and the costume 「粉色甜心小姐♪」.

This is an unofficial, non-commercial fan project. It is not affiliated with or endorsed by miHoYo/HoYoverse. Character and game rights remain with their respective rightsholders. The root MIT `LICENSE` applies to project code; it is not a grant of rights in the underlying game character or a separate MIT license for the character files. See `characters/elysia/README.md` for the asset inventory and use note. Do not include third-party reference images or game screenshots as distributable project assets.
