# Third-party and character asset notices

## Current Elysia character package

`characters/elysia/` contains the current maid Elysia source images, generated still image, icons and WebM animations. The visual design references Elysia from *Honkai Impact 3rd* and the costume 「粉色甜心小姐♪」. The precise provenance, rights holder and public redistribution permission for each image and derived animation have not yet been documented. Do not interpret this project's MIT `LICENSE` as a license for those files or the underlying character.

Before publishing these assets, record the source and redistribution permission for every source image, then confirm the same permission covers derived PNG, ICO and WebM files. If that cannot be confirmed, publish a code-only repository and omit the character package.
